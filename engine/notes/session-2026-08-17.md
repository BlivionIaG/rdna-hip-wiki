## Native HIP FP16 MoE

[../fp16-moe.md](../fp16-moe.md) + `kernels/fp16-moe.md`.

Two kernels, not one tile: decode skinny `M=1/2/4/8` (WG128 / N512 / K256, 4M fp32 acc/lane, M8 gated ≤64 VGPR) and prefill grouped 64×64×32 (WG256, 16 KiB double-buffer). Explicit `fdot2`, fp32 accum. `w13` packs adjacent gate/up (SiLU×up owner-local). `w2` has `combine_mode`; TP/EP default = unreduced routed rows. No RCCL inside the GEMM.

## Native HIP INT8 MoE (two routes)

[../int8-moe.md](../int8-moe.md) + `kernels/int8-moe.md`.

| Route | Compute | First use |
|---|---|---|
| W8A16 | i8→fp16 → `fdot2` | decode / tiny expert buckets |
| W8A8 | packed i8 → `sdot4`, i32 through K | prefill / fat buckets |

W8A16 is storage-INT8, not integer compute. W8A8 decode only if A is already i8 or fused quant wins. `(1,1)` scale is **per-token**. Crossover is `(rows/expert, K, N, scale scheme)`, not one global M.
