# W4A4 on gfx1030 — engine + kernel spec (explore)

Date: 2026-08-17. Explore only. Occupancy still first. Card: one W4A4 explore on [project 4](https://github.com/users/BlivionIaG/projects/4). Silicon: [kernels/w4a4.md](../kernels/w4a4.md) (tile locked). Do not edit `perf/rdna2_w4a16` from here.

**Verdict:** there is no FP4 MMA on gfx1030. The word “W4A4” is two different products:

| Name | Codes | Inner op on gfx1030 | Status |
|---|---|---|---|
| **MXFP4 / NVFP4 W4A4** | E2M1 × E2M1 | dequant A → fp16, then `fdot2` **or refuse** | Already locked. [nvfp4.md](nvfp4.md). `sdot8` on E2M1 is **wrong math**. |
| **Integer W4A4** (this page) | signed i4 × signed i4 | `V_DOT8_I32_I4` / `sdot8`, i32 through K, scale epilogue | **Explore.** After W8A8 `sdot4`. |

W4A4-native (Blackwell / FlashInfer / CUTLASS MX) stays **Dead**. This ticket is only the integer path.

Peak (GPUOpen RX 6950 XT table): IU4 **1024** vs packed FP16 **256**. That 4× only shows if **both** sides are i4 **and** the kernel is compute-bound (prefill). Decode M=1 is still weight-bandwidth — W4A16 `fdot2` may win; do not force A-quant every token.

## When this is legal

```
// keep
both W and A are packed signed i4 (two’s complement nibbles)
K % 8 == 0                         // 8×i4 / dword = one sdot8
i32 accum through K
C *= a_scale * w_scale             // epilogue, fp16/fp32
prefill first (M≥32)

// drop
V_DOT8 on E2M1 / NVFP4 / mxfp4 nibbles
sdot4 on i4×i4 (that is W4A8 after unpack-to-i8)
sdot8 on W4A8 (A is i8)
AITER / Marlin / FlashInfer FP4 MMA
bf16
```

W4A8 stays on [sdot4-explore.md](../kernels/sdot4-explore.md): unpack W i4→i8, then `sdot4`. Do not collapse W4A8 and W4A4 into one kernel.

## Format (we may have to invent the A side)

vLLM’s `CompressedTensorsW4A4Mxfp4` is **E2M1**, not this. On non-Blackwell it already falls back to W4A16 (Marlin). There is no sourced gfx1030 integer-W4A4 checkpoint.

Engine therefore owns **dynamic A quant** of a W4 checkpoint:

| Side | Pack | Scale |
|---|---|---|
| W | existing AWQ / WNA16 / compressed-tensors INT4, `uint32` = 8×i4, K-contiguous | per-group (g128 typical) |
| A | runtime: fp16 row → signed i4, same K pack | **per-token** (or per-token × group if we later need it) |

Sign-extend nibbles in VGPR. No LDS LUT (same llama.cpp #24438 rule as mxfp4).

Unknown until a checkpoint is named: zero-point or symmetric. Seed **symmetric signed i4 `{−8…7}`**. If the W pack is AWQ-asymmetric, keep W’s ZP and quantize A symmetric — two scale paths in the epilogue, not two DOTs.

## Kernel (silicon locked)

[kernels/w4a4.md](../kernels/w4a4.md): prefill **64×64×64 i4**, WG=256, A+B 4 KB, double-buf **8 KB**. `sdot8` into i32. Decode stays W4A16.

```
// per K dword
acc = __builtin_amdgcn_sdot8(a_i4x8, w_i4x8, acc, false);
// epilogue: acc.f32 * a_scale * w_scale → fp16 C
```

| Piece | Spec |
|---|---|
| Opcode | `__builtin_amdgcn_sdot8` / `V_DOT8_I32_I4`. No `sudot8`. |
| Pack | 8×i4 / `uint32`, LSB-first until a checkpoint locks it. `K % 8 == 0`. |
| Occupancy | no `waves_per_eu(1,1)`. |
| Dense name | `w4a4_gemm_rdna2` — do not rewrite `q_gemm_rdna2`. |
| MoE | `moe_w4a4_gemm_rdna2` only after dense prefill exists. Bitwidth-homogeneous. |
| A quant kernel | `quant_a_i4_rdna2` (or fused into the GEMM prologue). Prefill rows only. |

ISA dump must show `v_dot8_i32_i4`, not `v_dot2_f32_f16`, not an FP4 MMA.

## Dispatch

| Gate | Action |
|---|---|
| MXFP4 / NVFP4 “W4A4” key | **not this kernel.** [nvfp4.md](nvfp4.md) / live mxfp4 `fdot2`. |
| Integer W4 weights + explore flag | prefill: quant A → `w4a4_gemm_rdna2`. decode: W4A16 unless a later profile flips it. |
| W8A8 INT8 not landed | **do not open this.** A-quant + i32-DOT infrastructure comes from W8A8. |
| Occupancy still `waves_per_eu(1,1)` | do not land. |

Python: a new `is_supported_w4a4_int` **after** mxfp4/NVFP4 handlers, never instead of them.
