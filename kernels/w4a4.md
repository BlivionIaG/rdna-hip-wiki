# W4A4 integer — silicon / HIP contract

Engine: [engine/w4a4.md](../engine/w4a4.md). **Explore.** After W8A8 `sdot4`. Occupancy still first.

**Not MXFP4/NVFP4.** E2M1 × E2M1 stays unpack-A → `fdot2`. `sdot8` on E2M1 bits is wrong. This page is signed **i4 × i4** only.

## Native op

| | |
|---|---|
| Opcode | VOP3P `v_dot8_i32_i4` / `__builtin_amdgcn_sdot8`. **Not** VOP2 DOT8C — RDNA2 C-form is DOT4C/DOT2C only |
| Peak | IU4 **1024** ops/clk/CU (GPUOpen) vs IU8 512 / FP16 256 |
| Acc | i32 through K, `C *= a_scale * w_scale` in the epilogue |
| Pack | 8×i4 / `uint32`, K-contiguous, **LSB-first** until an INT4 checkpoint locks endianness, `K % 8 == 0` |
| Sign | seed symmetric `{−8…7}`. AWQ-asymmetric W keeps its ZP; A stays symmetric |

No `sudot8`. No LDS LUT. Sign-extend nibbles in VGPR.

## Tile (confirmed)

Explore order is **ConfigA-class LDS=0 first**, not LDS-first. Geometry matches live W4A16 ConfigA (`THREADS=256`, `N_TILE=1024`, `M_TILE=16`, `LDS=0`); inner op is `sdot8` on packed i4×i4.

| Rank | Seed | When |
|---|---|---|
| **1** | **ConfigA-class LDS=0** `sdot8`, `K_STEP ∈ {16,32}` | Prefill default. THREADS=256, N_TILE=1024, M_TILE=16, LDS=0 |
| **2** | **64×64×64 i4** LDS, WG=256, wave32 | Only if Rank 1 loses large-M. A 2 KB + B 2 KB = **4 KB**; double-buf **8 KB** (2 WG/WGP) |
| **3** | decode M=1/2/4 | **Leave.** Live W4A16 `fdot2` unless a later profile wins |
| **4** | workspace / MoE | Later. `moe_w4a4_gemm_rdna2` only after dense prefill exists |

Rank 2 step-up (still LDS, still after Rank 1): 64×64×128 i4, 8 KB single-buf, 16× `sdot8` / BK.

BK%8==0. Sequential `int` along K is conflict-free on 64 banks (same as i8).

```
// per K dword
acc = __builtin_amdgcn_sdot8(a_i4x8, w_i4x8, acc, false);
```

Sibling Explore: [opengfx1030/vllm-rdna#9](https://github.com/opengfx1030/vllm-rdna/pull/9) W4A8/`sdot4`. Own card / own draft PR. Merge gate closed. Do not mix.

W4A8 is **not** this: unpack W i4→i8, then `sdot4` ([sdot4-explore.md](sdot4-explore.md)).

## Kairic IU4 (do not consume)

[jcbtc/Qwen3.8-27B-IU4-Kairic-Edge](https://huggingface.co/jcbtc/Qwen3.8-27B-IU4-Kairic-Edge): Dual View GGUF + `.pfs` sidecars for `V_WMMA_I32_16X16X16_IU4` (u4 A × i4 W) on **gfx1151**. Take Dual View (decode GGUF / fat-M sidecar) only.

- gfx1030: no WMMA. Closest is `sdot8` **i4×i4**. Their mixed u4×i4 needs a rebias or unpack→`sdot4`.
- gfx1100: IU4 WMMA exists; IU4 peak is still 1024 (same as `sdot8`). Don’t eat their CK/`gfx1151` fragments.
- Not EXL3. Not MXFP4. After W8A8.
