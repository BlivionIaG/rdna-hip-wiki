## Take — dense (`w4a8_sdot4_rdna2.cu` / `.cuh`)

- **Math:** packed int4 W (same GPTQ-shuffled `[K/8,N]` buffer as W4A16) × int8 A → `__builtin_amdgcn_sdot4` / `v_dot4_i32_i8`. **Not** `fdot2`. **Not** `sdot8` (that is W4A4).
- **Wired tile name:** `a8_lds_k32_ag` (explore config id 8): `THREADS=256`, `NPT=4` → `N_TILE=1024`, `K_STEP=32`, `M_TILE=8`, `ASrc=kLds`, `A_GROUP=1` (per-(token, group) A scales).
- **Prefill-only:** host / selector gate `M >= 33` (`kW4a8MinRows` / `W4A8_MIN_ROWS`). Decode (`M < 33`) keeps W4A16 arms.
- **Eligibility (also C++):** gfx1030, fp16 A, `K % 32 == 0`, `K % group_size == 0`, group ∈ {32,64,128}, LDS fit via `w4a8_lds_fits` (some group- + K_STEP-aligned split ≤ 16 fits `M_TILE=8` rows of K + per-group scales under **64 KiB** LDS).
- **Internal Fallback:** `w4a8_gemm_rdna2` always returns a populated `[M,N]` fp16 tensor; on any miss it calls `gptq_gemm_rdna2_prefill` in-process. Python forward does not branch on a sentinel.
- **Launch:** `__launch_bounds__(C::THREADS)` → 256 for the wired config. Occupancy still FA-first elsewhere.
- **Ops / build:** `w4a8_act_quant_rdna2`, `w4a8_gemm_rdna2` in `ops.h` + `torch_bindings.cpp` under `VLLM_ROCM_GFX1030`; `csrc/rocm/w4a8_sdot4_rdna2.cu` in the gfx1030 `VLLM_ROCM_EXT_SRC` block.

## Take — MoE (`moe_w4a8_rdna2.cu`)

- Drop-in for `moe_gptq_gemm_rdna2` (+ trailing `use_v2_format`); accumulates into pre-zeroed `c`.
- Same opt-in env. **`resolve_w4a8_moe()` hard-off** when `VLLM_RDNA_MOE_RESIDENT` or `VLLM_RDNA_MOE_RESIDENT_SKINNY` (resident packing owns the weight buffers). Resident call sites pass `w4a8=False`.
- Act quant once over the batch via dense `w4a8_act_quant_kernel` (`a8_lds_k32_ag` layout); GEMM grid `(num_token_blocks, ceil(N/1024), ceil(K/256))`, 256 threads, `K_STEP=32`, `BLOCK_M ∈ {1,2,4,8}`.
- Stages block `BLOCK_M × 256` int8 into **2 KiB** LDS (avoids SGPR spill from live per-row A pointers).
- Internal Fallback → `moe_gptq_gemm_rdna2`. CMake: `moe_w4a8_rdna2.cu` in the same gfx1030 block; binding under `VLLM_ROCM_GFX1030`.

## MoE epilogue accum (tip `30b0bd4e`)

Shared helper `csrc/rocm/moe_accum_rdna2.cuh` for **both** `moe_gptq_gemm_rdna2` (W4A16) and `moe_w4a8_gemm_rdna2` (W4A8). Inner DOT unchanged (`sdot4` on this path; W4A16 MoE stays `fdot2`).

| Mode | Gate | Mechanism |
|---|---|---|
| **Default** | `VLLM_RDNA2_MOE_FP32_ACCUM` unset / false | packed-fp16 CAS-64 (`atomic_add_pk4_f16`) into caller pre-zeroed `c` |
| **Opt-in** | `VLLM_RDNA2_MOE_FP32_ACCUM=1` or per-call `fp32_accum=True` | `atomicAdd` fp32 into persistent per-(rows,N,device) scratch + one `fp32→fp16` cast. On gfx1030 this is **4 CAS-32 loops per row** (`global_atomic_cmpswap`), not a native fp32 atomic — the source comment's "native `v_global_atomic_add_f32` / no CAS" is gfx11+ ISA ([atomic-occupancy.md](../silicon/atomic-occupancy.md)). Result is still correct. |

Scratch is allocated eager (before capture); per-call zero is `hipMemsetAsync` (capture-legal). Schema default on the C++ binding may read `fp32_accum=True`; **production default is the env = false** via `_custom_ops.py`. Do not copy A/B ms or tok/s. sdot4 tile / 2 KiB LDS / resident hard-off unchanged.
