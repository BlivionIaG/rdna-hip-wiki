Date: 2026-09-01. Tip **`rdna2_extras` @ `83de31cf`** (read-only). FA pin stays closed. Occupancy leftover is **FA prefill `(N, 1)` / LDS 64 KiB WG**, not this format. Do not invent tok/s. Do not land this before that leftover.

Do **not** silently requantize a W8A16 checkpoint into this numeric contract.

## `sdot4` vs unpack → `fdot2`

```
W8A16 (live MoE):   load i8 W → cvt fp16 → fdot2(A16, W16)     // A stays fp16
W8A8  (spec):       quant A to i8 → sdot4(A8, W8) → i32        // both sides i8
W8A8-FP8 (live):    E4M3 → fp16 bits → fdot2                   // not integer
W4A8  (explore):    nibble → i8, then sdot4                    // not sdot8
W4A4 int (explore): both i4 → sdot8                            // after W8A8
MXFP4 / NVFP4 A4:   E2M1 unpack → fp16 → fdot2                 // sdot8 on E2M1 is wrong math
```

Unpack→`fdot2` is **not** a W8A8 implementation. It is W8A16. Using it as a “temporary sdot4” ships the wrong opcode and never sees the 512 IU8 pipe.

`sudot4` / `V_DOT4_I32_IU8` is gfx11+ (`dot8-insts`). gfx1030 has signed `sdot4` and unsigned `udot4` only — do not mix signs.

## Occupancy

`__launch_bounds__` does **not** shrink LDS. Occupancy = min(VGPR, LDS, SIMD). Addressable LDS per WG is **64 KiB**; WGP pool 128 KiB; banks 64×4 B. Recipe 9 (8–16 KiB) is not the FA leftover. Do not pin this kernel `(N, 1)`. Do not treat RMSNorm HIP AOT as a reason to open this card.

## Does this change extras / UNC?

**No.** Spec stays spec. No GEMM to retip. FA pin closed. No Linear ticket.
