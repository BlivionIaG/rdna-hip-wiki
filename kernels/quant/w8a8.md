# W8A8 INT8 / `sdot4` — extras vs contract

Date: 2026-09-01. Tip **`rdna2_extras` @ `83de31cf`** (read-only). FA pin stays closed. Occupancy leftover is **FA prefill `(N, 1)` / LDS 64 KiB WG**, not this format. Do not invent tok/s. Do not land this before that leftover.[^c-83de31cf][^isa]

Companions: [sdot4-explore.md](sdot4-explore.md), [int8-moe.md](../gemm-moe/int8-moe.md), [w8a8-fp8.md](w8a8-fp8.md), [w8a8-mxfp4.md](w8a8-mxfp4.md) (study), [silicon/valu.md](../../silicon/valu.md), [silicon/lds-tiles.md](../../silicon/lds-tiles.md) recipe 9.[^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h]

gfx1030 has **no** WMMA / MFMA / FP8 unit. Integer inner op is `V_DOT4C_I32_I8` / `__builtin_amdgcn_sdot4`. Peak IU8 **512** ops/clk/CU vs packed FP16 **256** (GPUOpen RX 6950 XT table) — the 2× only shows when **both** sides are integer i8 **and** the kernel is compute-bound.[^isa][^gpuopen]

## What extras already has (do not relabel)

CMake `VLLM_GPU_ARCHES MATCHES gfx1030` + unconditional EXL3/layernorm list @ `83de31cf`. **No** `sdot4` GEMM object.[^c-83de31cf]

`csrc/rocm/ops.h` names `gemm_w8a8_fp8_dense` — FP8 storage, `fdot2` compute. There is **no** `gemm_w8a8_rdna2` / `moe_w8a8_rdna2` / act-quant HIP.[^f-83de31cf-ops-h]

EXL3 `cb==2` (`mul1`) uses `sdot4` vs `0x01010101` **inside the codebook**, not as a GEMM. Produce stays `3inst`→`fdot2`. 6bpw `mul1` is lm_head **dequant only**.[^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h]

## Contract (not on the branch)

| Piece | Contract | Status @ `83de31cf` [^c-83de31cf] |
|---|---|---|
| **Act quant** | fp16 A → signed i8, pack 4 K-bytes / dword, `K % 4 == 0`. Dynamic per-token scale `[M,1]`. Shape `(1,1)` is **per-token**, not per-tensor (rank/stride, never `numel()==1` alone). Prefill: separate graph-safe quant kernel. Decode: fuse only if it does not serialize the GEMV. | **Absent** [^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h] |
| **Dense W8A8** | Explicit `__builtin_amdgcn_sdot4(a,b,acc,false)` → i32 through K. Epilogue `fp16(acc * a_scale[row] * w_scale[col])`. No AITER `(32,16)` shuffle. | **Absent** [^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h] |
| **MoE W8A8** | Same packing. Consume existing sorted/aligned routed-token metadata. `w13` keeps gate/up adjacent. Empty expert / sentinel `-1` no-touch. Dual-route with W8A16: choose **outside** the K loop. | **Absent** (`moe_w8a16_rdna2` is the W8A16 route only) [^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h] |
| Prefill seed | **64×64×64 i8**, WG=256, A+B 4+4 KB, double-buf **16 KB** (recipe 9). Sequential `int` along K is conflict-free on 64 banks. | Spec [^isa] |
| Decode `M=1/2/4` | Skinny. A in LDS (`K·M` bytes). Eligible only if A is already i8/static, or fused quant beats W8A16 end-to-end. | Spec [^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h] |

Do **not** silently requantize a W8A16 checkpoint into this numeric contract.[^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h]

## `sdot4` vs unpack → `fdot2`

```
W8A16 (live MoE):   load i8 W → cvt fp16 → fdot2(A16, W16)     // A stays fp16
W8A8  (spec):       quant A to i8 → sdot4(A8, W8) → i32        // both sides i8
W8A8-FP8 (live):    E4M3 → fp16 bits → fdot2                   // not integer
W4A8  (explore):    nibble → i8, then sdot4                    // not sdot8
W4A4 int (explore): both i4 → sdot8                            // after W8A8
MXFP4 / NVFP4 A4:   E2M1 unpack → fp16 → fdot2                 // sdot8 on E2M1 is wrong math
```

Unpack→`fdot2` is **not** a W8A8 implementation. It is W8A16. Using it as a “temporary sdot4” ships the wrong opcode and never sees the 512 IU8 pipe.[^gpuopen]

`sudot4` / `V_DOT4_I32_IU8` is gfx11+ (`dot8-insts`). gfx1030 has signed `sdot4` and unsigned `udot4` only — do not mix signs.[^isa][^clang-dot][^llvm-gfx1030]

## Occupancy

`__launch_bounds__` does **not** shrink LDS. Occupancy = min(VGPR, LDS, SIMD). Addressable LDS per WG is **64 KiB**; WGP pool 128 KiB; banks 64×4 B. Recipe 9 (8–16 KiB) is not the FA leftover. Do not pin this kernel `(N, 1)`. Do not treat RMSNorm HIP AOT as a reason to open this card.[^isa]

## Does this change extras / tickets?

**No.** Spec stays spec. No GEMM to retip. FA pin closed. No ticket.[^f-83de31cf-CMakeLists-txt][^f-83de31cf-ops-h]
