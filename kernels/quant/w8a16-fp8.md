# W8A16-FP8 — silicon / HIP contract

Live: `q_gemm_w8a16_fp8_rdna2.cu`, `moe_w8a16_fp8_rdna2.cu`, `qdq_fp8_rdna2.cuh`. **Incomplete.** Storage looks FP8; compute is `fdot2`.[^f-9ac015d0-q-gemm-w8a16-fp8-rdna2-cu][^f-9ac015d0-moe-w8a16-fp8-rdna2-cu][^f-9ac015d0-qdq-fp8-rdna2-cuh]

No FP8 unit on gfx1030. 256-entry `__constant__` LUT, host-built OCP E4M3 → fp16 (`ensure_fp8_lut_populated`). Then same `dequant_fp8_8_fp16` + `fdot2` as W8A16.[^f-9ac015d0-qdq-fp8-rdna2-cuh]

## Native ops

| Step | Op |
|---|---|
| Load W | 1 byte / elem, E4M3 [^f-9ac015d0-qdq-fp8-rdna2-cuh][^f-9ac015d0-q-gemm-w8a16-fp8-rdna2-cu] |
| E4M3 → fp16 | LUT (MoE) or `fp8_e4m3_to_fp16_bits` (dense) [^f-9ac015d0-qdq-fp8-rdna2-cuh] |
| × group scale | half2 broadcast [^f-9ac015d0-qdq-fp8-rdna2-cuh][^f-9ac015d0-q-gemm-w8a16-fp8-rdna2-cu] |
| A (fp16) · W | `V_DOT2_F32_F16` [^isa] |

Do **not** call this W8A8. A is fp16. Do **not** use `sdot4`.[^f-9ac015d0-qdq-fp8-rdna2-cuh][^f-9ac015d0-q-gemm-w8a16-fp8-rdna2-cu]

One-time transpose fix landed in `9ac015d0`. GPU verify of all shapes still open.[^c-9ac015d0]
