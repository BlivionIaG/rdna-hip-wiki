# W8A16-FP8 — silicon / HIP contract

Live: `q_gemm_w8a16_fp8_rdna2.cu`, `moe_w8a16_fp8_rdna2.cu`, `qdq_fp8_rdna2.cuh`. **Incomplete.** Storage looks FP8; compute is `fdot2`.

No FP8 unit on gfx1030. 256-entry `__constant__` LUT, host-built OCP E4M3 → fp16 (`ensure_fp8_lut_populated`). Then same `dequant_fp8_8_fp16` + `fdot2` as W8A16.

## Native ops

| Step | Op |
|---|---|
| Load W | 1 byte / elem, E4M3 |
| E4M3 → fp16 | LUT (MoE) or `fp8_e4m3_to_fp16_bits` (dense) |
| × group scale | half2 broadcast |
| A (fp16) · W | `V_DOT2_F32_F16` |

Do **not** call this W8A8. A is fp16. Do **not** use `sdot4`.

One-time transpose fix landed in `9ac015d0`. GPU verify of all shapes still open.
