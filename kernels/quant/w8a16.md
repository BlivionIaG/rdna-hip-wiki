# W8A16 — silicon / HIP contract

Engine row: [engine/serving-stack/fork-delta.md](../../engine/serving-stack/fork-delta.md). Live files (still present and built at `1dc3bac4`): `qdq_8_rdna2.cuh`, `moe_w8a16_rdna2.cu` (op `moe_w8a16_gemm_rdna2`).[^w8-tip] **Incomplete.** No `q_gemm_w8a16_rdna2.cu` at `9a344444`, and none at `1dc3bac4` either. The only dense W8A16 op at the tip is the FP8 one (`gemm_w8a16_fp8_dense`, see [w8a16-fp8.md](w8a16-fp8.md)).[^w8-tip][^c-9a344444][^f-9a344444-qdq-8-rdna2-cuh][^f-9a344444-moe-w8a16-rdna2-cu]

**Not W8A8.** Activations stay fp16. Inner loop is `fdot2`, not `sdot4`.[^f-9a344444-qdq-8-rdna2-cuh][^f-9a344444-moe-w8a16-rdna2-cu]

## Native ops

| Step | Op |
|---|---|
| Load W | `uint64` = 8×i8 [^f-9a344444-qdq-8-rdna2-cuh][^f-9a344444-moe-w8a16-rdna2-cu] |
| i8 → fp16 | `__int2half_rn` [^f-9a344444-qdq-8-rdna2-cuh][^f-9a344444-moe-w8a16-rdna2-cu] |
| scale / zero | `__hfma2` (fp16) [^f-9a344444-qdq-8-rdna2-cuh][^f-9a344444-moe-w8a16-rdna2-cu] |
| A · W | `V_DOT2_F32_F16` (`__builtin_amdgcn_fdot2`) [^isa] |

Same DOT as W4A16. Wider load, no nibble pack.[^f-9a344444-qdq-8-rdna2-cuh][^f-9a344444-moe-w8a16-rdna2-cu]

## Status

MoE in-tree. Dense file absent at tip. Treat as incomplete. Occupancy still first (FA / skinny).
